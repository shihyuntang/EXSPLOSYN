# EXSPLOSYN

**EXOplanetary Spotted Photosphere LOw-mass SYNthesizer**

EXSPLOSYN simulates high-resolution spectra and photometric variability from
spotted low-mass stars. It integrates local spectra across a rotating stellar
disk with cool and hot active regions.

## Features

- Multiple circular active regions with individual positions, sizes, and temperatures.
- Synthetic spectra from PHOENIX (2013) and custom SYNMAST libraries.
- High-resolution spectra, radial velocities, and the FeOH equivalent-width ratio as functions of rotational phase.
- Relative photometric light curves, apparent effective temperatures, and apparent luminosities as functions of rotational phase.
