# EXSPLOSYN roadmap

The main development goals are listed below. Priorities and version assignments
may change based on testing and user feedback.

## Planned releases

- **v0.9.x:**
  - Improvements based on test-group feedback.
- **v1.0.x:**
  - First official public release.
- **v1.1:**
  - Forward-model fitting and faster repeated model evaluations.
  - Support PHOENIX 2025 spectral libraries.

## Future features

- Support additional user-supplied spectral libraries.
- Extend support to larger active regions.
